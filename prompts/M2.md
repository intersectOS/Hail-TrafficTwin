# Track A — M2 Population and baseline
Owner files: `sim/population/`, `sim/daytypes/`, `sim/metrics.py`, `sim/schemas.py` (create), `tests/test_population*.py`, `docs/status/trackA.md`, `docs/assumptions-trackA.md`, `docs/population.md`.

Deliver PROJECT.md sections 6.2, 6.3 and 9.2, using the `demand-modeler` subagent for the modelling and `data-scout` for any figure you need to source.

1. Zones (`sim/population/zones.py`): districts from `data/jeddah/districts.geojson` as TAZs; census control total 3,712,917 (place Jiddah, GASTAT 2022) spread by residential building footprint area from `data/jeddah/buildings.geojson` (document the assumption); jobs by OSM land use and POI density; school seats from OSM schools. Snap each zone to candidate edges inside the main strongly connected component (`python -m sim.network.netinfo scc`).
2. Population (`synthesize.py`): persons with age group, status, sector, car availability, household; deterministic with `--seed`; cached to Parquet with a population hash; `--sample 0.10 | 0.25 | 1.0`.
3. Activity chains (`activities.py`) and day types (`sim/daytypes/weekday.yaml`, `friday.yaml`, `ramadan_weekday.yaml`, `saturday.yaml`, `umrah_season.yaml`): start-time distributions per segment, prayer-time keyed mosque trips (compute with the `adhanpy` or `adhan` package for the simulated date), evening leisure; every number with `source:` or `assumption:`.
4. Modes (`modes.py`): fixed shares by segment (car, ride-hail, bus where a route exists within 500 m of both ends, walk); export only vehicle trips to SUMO (`export_trips.py`), sorted by departure.
5. Baseline (`python -m sim.runner --baseline --daytype weekday --sample 0.10 --seed 1`): duaIterate with few iterations and routing threads, routes cached by (network hash, population hash, day type, seed); edgeData every 300 s; tripinfo; emissions summary. Measure runtime and peak memory at 10 %, then 25 %. Record the sampling decision for the default (`--scale` capacity scaling).
6. Metrics (`sim/metrics.py`): city KPIs from PROJECT.md 9.8 (delay, speed, VKT, VHT, throughput, peak spreading, CO2/NOx, per-district) written to `runs/<id>/metrics.json` and Parquet.
7. Validation plots (departure histogram, trip length, trips per person) to `runs/<id>/plots/`; sanity ranges in `docs/population.md`.
8. Fidelity test (`sim/fidelity.py`, PROJECT.md 9.4): same demo window in meso and micro, hourly comparison report; quote its caveats in the metrics report template.
Done when: 10 % weekday baseline runs end to end from one command with metrics, 25 % runtime is measured and recorded, tests pass on the demo window, verifier passes. Write `M2: done`.
