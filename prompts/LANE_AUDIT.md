# Track C — Lane audit from satellite imagery
Owner files: `sim/network/lane_audit.py`, `data/osm/fixes/imagery-lanes.yaml`, `data/osm/fixes/imagery-eval.json`, `tests/test_lane_audit*.py`, `docs/status/trackC.md`, `docs/assumptions-trackC.md`, `docs/lane-audit.md`. Do NOT overwrite `data/jeddah/jeddah.net.xml`; write the rebuilt network to `data/jeddah/jeddah.lanes.net.xml` and its build json beside it.

Follow the `lane-audit-imagery` skill. Goal: replace the class-default lane counts on untagged major roads with counts read from aerial imagery, with a measured accuracy.
1. Inventory: list untagged `trunk`, `primary`, `secondary` (and `motorway` if untagged) ways in the Jeddah extract, grouped by OSM way id, with length and a mid-segment sample point and bearing. Report counts per class.
2. Calibration first: pick 40 ways that DO have `lanes` tags (stratified by class), fetch imagery crops, let the `imagery-analyst` subagent count lanes blind, compare with the tags, and write `imagery-eval.json` (agreement rate, confusion by class, chosen confidence threshold). If agreement is under 80 % at the threshold, stop, write the findings, and mark `LANE_AUDIT: blocked - accuracy`.
3. Audit: process untagged ways by priority (motorway, trunk, primary, then secondary) within a cap of 1,500 images; batches of 20 crops per subagent call, structured JSON back; accept only results at or above the threshold; write `imagery-lanes.yaml` entries with `lanes` per direction (as `lanes` or `lanes_min` fixes the existing `sim/network/fixes.py` understands; extend it additively if a per-direction field is missing), `source: "Esri World Imagery tile z<z>/<x>/<y>, accessed <date>"`, `confidence`, `method: imagery-analyst`.
4. Rebuild to `jeddah.lanes.net.xml`, re-run the city smoke (`--net`), and record lane-km, teleports and runtime before and after in `docs/lane-audit.md` with a dozen example crops under `docs/img/lane-audit/`.
Attribution: add Esri World Imagery to `NOTICE`. Done when the eval and audit files exist, the rebuilt network passes the smoke run, tests pass, verifier passes. Write `LANE_AUDIT: done`.
